指尖花开 · 手势控制绽放
==============================

一、这是什么
  一个本地网页：摄像头识别拇指与食指的距离，控制一朵花的开合。
  所有资源都在本文件夹内，不联网也能运行。

二、怎么打开（Windows）
  1. 先把整个文件夹解压出来（别只挑几个文件）。
  2. 双击「启动网页.bat」，会弹出一个黑色窗口。
     这个窗口不能关，关了服务就断。
  3. 打开 Chrome 或 Edge，地址栏输入：
         http://localhost:8000
  4. 浏览器询问摄像头权限时，点「允许」。
  5. 把拇指和食指伸进右下角小窗：捏紧 = 花苞，张开 = 盛开。

三、怎么打开（Mac）
  1. 解压后，在该文件夹上右键 →「服务」→「新建位于文件夹位置的终端窗口」。
  2. 输入：  python3 serve.py     回车。
  3. 用 Chrome / Edge / Safari 访问 http://localhost:8000
  （也可双击「启动网页.command」；若被系统拦下，请到「系统设置 → 隐私与安全性」允许。）

四、三条铁律
  1. 不能直接双击 index.html。
     file:// 协议下，浏览器会拦掉摄像头与脚本模块，页面不会工作。
  2. 必须用 localhost 打开。
     用局域网 IP（如 192.168.1.5:8000）打开，页面能看，但摄像头会被浏览器锁死。
  3. 那个黑色窗口 / 终端窗口要一直开着。

五、打不开时
  - 页面先黑一下：正常。首次要加载 192 张花帧与手部模型，约 1-3 秒。
  - 右下角提示「摄像头未启用」：点地址栏左侧的锁形或摄像机图标，
    允许摄像头后按 Ctrl+Shift+R 刷新。
  - 提示找不到 python：先装 Python 3（python.org），安装时勾选 Add to PATH。
  - 8000 端口被占用：关掉别的占用程序，或改 serve.py 里的 PORT。

六、文件说明
  index.html            页面本体
  frames/               192 张花帧（花苞到盛开，6.4MB）
  hand_landmarker.task  手部识别模型（7.5MB）
  vision_bundle.js      识别库
  wasm/                 运算核心
  lotus-bloom.mp4       备用视频（仅在帧图缺失时启用）
  serve.py              本地服务脚本（负责正确的 MIME 头）
  启动网页.bat          Windows 一键启动
  启动网页.command      Mac 一键启动

七、顺带一提
  每台电脑的摄像头权限都要各自授权一次，这是浏览器的规矩，无法代劳。
